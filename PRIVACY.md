# Privacy Policy

Effective date: October 15, 2026.

LeetHub synchronizes accepted LeetCode submissions to a GitHub repository selected by the user. It does not operate an analytics service or a developer-controlled server that receives user data.

## Data used

The extension stores a user-provided GitHub token, GitHub account name, selected repository, settings, upload results, and synchronized problem statistics in local extension storage. Token access is restricted to trusted extension contexts. The token is sent to GitHub only to authenticate API requests.

The extension uses the browser's existing LeetCode session to retrieve selected accepted submission details, including submitted source code, problem information, language, runtime, and memory. It observes completion of LeetCode submission-check requests to identify submissions. It does not record general browsing history or requests outside LeetCode.

Submitted source code and problem information are sent to GitHub to create files and commits in the selected repository. A public repository makes these files publicly accessible. The user chooses the repository and can pause uploads, unlink it, or remove the extension.

## Sharing and retention

Data is transmitted to LeetCode and GitHub solely to perform the requested synchronization. LeetHub does not sell user data, use it for advertising, or provide it to data brokers. LeetCode and GitHub process API requests under their own policies.

Local data remains in the Chrome profile until cleared or the extension is removed. Removing the extension does not delete GitHub commits or revoke tokens. Revoke the token in GitHub settings when discontinuing use. Files and commits already uploaded must be removed through GitHub if desired.

The extension does not execute remote code, collect payment information, or transmit data to developer-controlled infrastructure.

## Questions

Use the repository's issue tracker for privacy questions. Do not include tokens or private source code in an issue. Security reports should follow the repository's security policy.
